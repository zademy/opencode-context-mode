# Open Context Mode Insight

## Instructions

1. Call the `open_ctx_insight` MCP tool (no parameters). It opens
   <https://open-context-mode.com/insight> in the default browser.
2. Report that it opened, and repeat the URL so the user can open it by hand if the
   browser did not come up.
3. Sign-in and pricing live on that page — point there rather than restating them.
